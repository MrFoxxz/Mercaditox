# Capturas para la guía de Mercaditox

Guarda las capturas verticales en PNG, con datos de ejemplo y estos nombres. Estas imágenes servirán para una versión posterior de la guía.

| Archivo | Pantalla que debe verse |
| --- | --- |
| `01-lista-principal.png` | Una lista con varios productos, el encabezado, el botón «?» y los botones para comprar. |
| `02-catalogo.png` | El catálogo abierto con una categoría o Favoritos y al menos dos productos seleccionados. |
| `03-detalle-precios.png` | El detalle de un producto con cantidades y dos precios de tiendas. |
| `04-ordenar-pasillos.png` | El panel Ordenar pasillos con las flechas visibles. |
| `05-modo-compra.png` | Modo compra con pendientes y los totales fijos en la parte inferior. |
| `06-exportar-lista.png` | El panel Exportar lista con las opciones de PDF y WhatsApp. |
| `07-historial.png` | El historial con al menos un mercado de ejemplo ya cerrado. |
